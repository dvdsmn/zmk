★ Changes applied (shown in gold):
1. DEL → 🌐 GLOBE on Mac Layer 0 (top-right key). On macOS, forward-delete is ⌘ Cmd + Backspace so DEL is not needed there. Windows layers keep DEL unchanged.
2. Fn + Backspace → DEL on Mac Fn Layer 1 — restores forward-delete access on macOS without dedicating a key to it.
3. Fn + - (hold 3s) → UF2 Bootloader on both Fn layers — enters flash/DFU mode for firmware updates.

🌐 GLOBE & Karabiner: Set the Keychron to "Ignore this device" in Karabiner-Elements Devices tab — GLOBE works natively without Karabiner.

Special combos (Fn layer only — hold all keys for 3 seconds unless noted)

KeysActionNotes
Fn + - (hold 3s) ⚡ UF2 Bootloader / Flash mode Enters DFU mode for firmware updates. Keyboard mounts as USB drive. Also: hold pinhole reset while plugging in USB.
Fn + J + Z Firmware recovery mode Resets the keyboard transport; use if it stops responding
Fn + X + L F-key / Media key swap (Function Lock) Swaps F-row and Fn+F-row bindings. Default: F-row=media, Fn=F1–F12. After toggle: F-row=F1–F12, Fn=media. Saved to flash. Tracked separately for Mac and Win.
Fn + B Battery level indicator Triggers the battery LED display
Fn + Win (hold 3s) Switch Win-key mode (OUT_FN_WIN) Toggles Windows key lock / function behaviour

Entering flash/DFU mode (hardware method): Unplug the USB cable. Set the keyboard to WIN mode and CABLE. Hold down the pinhole reset button, then plug in the USB cable while keeping the button held. Release the button — the keyboard mounts as a USB drive. Drag or copy zmk.uf2 onto it.

Mac vs Windows mode: The physical slide switch on the keyboard body maps to the hardware row key. In Mac position the key sends nothing; in Windows position it permanently "holds" the key, which activates Layer 2 (Windows). That is why Layer 2's Mac/Win key is bound to none — it would otherwise loop.

Transparent keys (—): A grey dash means the key "falls through" to the layer below. For example, all letter and number keys in the Fn layers pass through to the default layer, so you can still type normally while holding Fn (only the overridden keys change).
